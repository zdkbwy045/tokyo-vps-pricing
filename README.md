## 下单前要确认的三件事

**退款窗口是 14 个自然日，但有例外。** 官方 FAQ 原话是 VPS 产品可在 14 个日历日内退款，exceptions apply。也就是说退款不是无条件的，下单前把完整条款读完，别默认"不满意随时全退"。
